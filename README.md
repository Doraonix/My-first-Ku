## 4. 浏览器手动验收

以下是待实际操作的验收步骤，不代表已经通过浏览器验收。以“番茄炒蛋”尚未收藏为起点；已有其他收藏可以保留。

1. 打开页面，确认能看到“下一餐，吃点什么？”。不选主要食材，点击“看看能做什么”，应提示至少选择一种主要食材。
2. 只勾选“番茄”，难度选“不限”，点击推荐。应出现番茄炒蛋（缺鸡蛋）和番茄鸡蛋炖豆腐（缺北豆腐、鸡蛋）；调料单独列出。
3. 打开番茄炒蛋的“查看做法”。应看到完整食材、用量、步骤及相同缺料提示。点击“收藏”，按钮应变为“取消收藏”，收藏列表出现该菜。
4. 修改选材或难度，旧推荐与旧详情应清除，收藏仍在。直接从收藏打开该菜，此时未重新推荐，应只展示完整资料，不宣称材料齐全。
5. 刷新页面，再关闭网页标签并用同一浏览器重新打开 http://localhost:5173/。番茄炒蛋应仍在收藏列表。
6. 从收藏列表或详情中取消收藏；刷新并关闭标签后重新打开，该菜不再出现在收藏列表；若没有其他收藏，应显示“还没有收藏的菜”。原菜品仍可以推荐找到。
